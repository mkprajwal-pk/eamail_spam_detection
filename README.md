Email Spam Detection 📧

About the Project

This is a Machine Learning project that detects whether an email is Spam or Not Spam using Python.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

Algorithm

- TF-IDF Vectorizer
- Multinomial Naive Bayes

Features

- Email data preprocessing
- Spam email classification
- Model training and testing
- Interactive spam checker

How to Run

1. Install the required libraries:
   pip install pandas scikit-learn jupyter
2. Open the Jupyter Notebook.
3. Run all the cells.
4. Enter an email to check whether it is spam or not.
